# ai-traffic-data_anlysis
# 다중회귀 및 WLS로 규명한 주거비와 통근 이동격차 분석

> AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전  
> 송채영 · 설수현 · 권진서

## 1. Project Overview
서울 및 수도권을 대상으로 주거비와 통근시간의 관계를 분석하고,  
단순한 주택가격보다 도심 접근성과 교통 연결성이 통근격차에 미치는 영향을 확인했습니다.  
또한 실제 영향 인구를 반영해 교통정책 우선지역을 도출했습니다. 

## 2. Data
- 서울 생활이동데이터
- 아파트 매매가
- 대중교통 및 지하철역 정보
- 행정구역 경계
- 경제활동인구 및 타지역 통근 취업자 데이터 

## 3. Analysis
- 서울 25개 자치구: 단순회귀, 다중회귀, Z-score Trade-off 분석
- 수도권 읍면동: 사분면 분류, K-means, WLS
- WLS 잔차와 통근 취업자 수를 결합한 정책 시급도 산출

## 4. Key Results
- 서울에서는 집값보다 도심거리가 통근시간을 더 잘 설명함
- 관악·은평·금천·강서가 주요 통근부담 지역으로 확인됨
- 수도권에서는 영향 인구를 고려했을 때 화성·수원·성남 등 신도시가 주요 정책 우선지역으로 나타남 

## 5. Tools
Python · Jupyter Notebook · pandas · statsmodels · scikit-learn
